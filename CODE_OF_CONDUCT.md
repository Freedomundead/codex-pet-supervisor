# Code of Conduct

Codex Pet Supervisor is an open-source community project. Keep discussions technical, respectful, and useful.

## Expected behavior

- Be respectful when disagreeing.
- Critique code and ideas, not people.
- Provide reproducible details for bugs.
- Respect privacy; do not post another person's credentials, private files, account data, or conversations.
- Give credit for substantial contributions.

## Unacceptable behavior

Harassment, threats, discrimination, doxxing, deliberate disruption, or publishing private information without permission are not acceptable.

Project maintainers may edit, lock, or remove contributions that violate these expectations.
